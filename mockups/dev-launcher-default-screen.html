📌 Pin button (new)
A small pin icon appears on the right of every row. Tap it to set that flow as the default. Tapping an already-pinned row clears the default. Inactive pins are dim; the active one glows green.
DEFAULT badge (new)
The defaulted row shows a small green DEFAULT chip inline with the flow name so it's visible at a glance, even when a different row is the active selection.
Subheading chip (new)
The subheading shows 📌 Welcome (or whichever is pinned) so you always know the default without scanning the list. Disappears when no default is set.
Persistence
Stored in expo-secure-store under dev_default_flow. Survives full reloads (shake → Reload). On app launch, the routing guard reads the default and navigates there directly — the launcher only appears if no default is set.
