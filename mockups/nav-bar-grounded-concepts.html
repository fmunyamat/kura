Bottom Nav — six non-floating directions
Every bar here is anchored flush to the bottom edge, full width — no floating pill. All six stay inside Kura's existing world (solid deep-green surface, single lime accent, mono labels) and differ in how they mark the active tab. Tabs shown: Today · Tasks · Learn · Settings. The active state cycles automatically so you can see each one move.
